### ① 열차혼잡도 — ⚠️ 1호선만, 오래됨
- [부산교통공사_1호선 열차혼잡도 정보_20210831](https://www.data.go.kr/data/15139787/fileData.do)
  - 1호선 차량별 혼잡도를 시간대·역별로 측정해 월 단위 집계, **1~8호차별 혼잡률(%)**

  - 업데이트 주기 "수시(1회성)". 2~4호선 혼잡도 공개 데이터는 **찾지 못함** (2025-11 기준 공사 개방목록 82건에도 1호선만)
- 참고 수치 (비공식·보도)
  - 1호선 최고혼잡 구간 부전→서면, 2024년 102%, 2025년 105% (나무위키 정리, 공식 출처 확인 필요)
  - 2013년 공사 전 노선 조사(부산일보): 출근시간 평균 3호선 60% · 1호선 58% · 2호선 47% · 4호선 39%. 1호선 정원 970명을 100%로 정의. **오래된 자료라 비율 참고용으로만**

## 4. 제안: 데이터별 처리 방식

| 명세 변수 | 처리 | 근거 데이터 |
| :--- | :--- | :--- |
| `travel_time_sec` | **실데이터** | ④ 역간 소요시간 |
| `board`, `alight` | **실데이터** (2026년 1~8월 평일 평균, 4개 시간대) | ② 승하차인원 |
| `congestion_rate` 1호선 | **실데이터** (호차 평균) | ① 1호선 혼잡도 |
| `congestion_rate` 2~4호선 | **추정**: 1호선에서 "구간 재차인원 ↔ 혼잡률" 관계를 학습 → 2~4호선 승하차로 재차인원 추정 → **호선별 편성 정원(⑤)으로 나눠 혼잡률 환산** | ① + ② + ⑤ |
| 수영역 승하차 분리 | **전처리**: 2호선 자료에 합산된 2·3호선 인원을 인접 역 승하차 비율로 분할 | ② |
| `facility_score` | **실데이터 기반 점수화** | ③-b 편의시설, 교통약자 대체경로 복잡도 |
| `transfer_distance_m`, `transfer_time_sec` | **추정** (연산 실측 109초 기준 + 구조별 배율), 화면에 "추정" 표기 | ③ |
| `crowd_factor M(k,t)` | **실데이터 기반**: 환승역 시간대별 승하차 합계를 0~1로 스케일 | ② |

> **발표 포인트**: 공공데이터 미개방(2~4호선 혼잡도)을 숨기지 않고, 1호선 실측 패턴을 타 노선에 옮길 때 생기는 오차와 그 보정 방법(정원 환산 등)을 데이터 리터러시 관점에서 설명한다.
