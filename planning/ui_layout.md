## 2. 컴포넌트 명세

| 컴포넌트 | 파일 | 입력 | 동작 |
| :--- | :--- | :--- | :--- |
| 컨트롤 패널 | `ui/controls.js` | 가중치 4개, 프리셋 | 값 변경 즉시 `onChange(weights)` 호출 |
| 경로 카드 | `ui/routeCards.js` | 정렬된 경로 + 점수 | 순위 변경 시 위치 트랜지션 (FLIP) |
| 파동 그래프 | `ui/waveChart.js` | 경로별 (시간, 스트레스) 시퀀스 | 환승 지점 스파이크, 서면 붉은 피크 강조 |
| 레이더 차트 | `ui/radarChart.js` | 경로별 5대 지표 | 경로 겹침 비교 |
| 노선 미니맵 | `ui/schematicMap.js` | 네트워크 + 선택 경로 | 선택 경로 발광 + 파티클 흐름 |
