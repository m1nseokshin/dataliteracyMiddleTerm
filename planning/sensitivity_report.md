# 🎚️ 민감도 분석 (자동 생성)

> `scripts/sensitivity.mjs`가 만든 문서입니다. 추정값과 설계 계수를 흔들었을 때 시나리오 결론이 유지되는지 확인합니다.
> 비교 대상은 두 시나리오에서 "서면을 거치는 경로"입니다. 시간대 4개(출근·낮·퇴근·야간) × 가중치 5세트(기본 + 프리셋 4개) = 20조합에서 이 경로가 몇 번 가장 피로한 경로로 나오는지 셉니다.

### A 동래→센텀시티 — "서면 환승" 경로가 꼴찌(가장 피로)로 나온 횟수 / 시간대 4 × 가중치 5 = 20조합

| 흔든 조건 | 꼴찌 | 1위 |
| :-- | --: | --: |
| 기준 | 20/20 | 0/20 |
| 2~4호선 혼잡 추정 ×0.7 | 20/20 | 0/20 |
| 2~4호선 혼잡 추정 ×1.3 | 20/20 | 0/20 |
| 3호선만 ×2 (환승객 누락 보정) | 20/20 | 0/20 |
| 3호선만 ×3 | 20/20 | 0/20 |
| 환승시간 가정값 ×0.5 (서면·수영·동래) | 20/20 | 0/20 |
| 환승시간 가정값 ×1.5 | 20/20 | 0/20 |
| 환승 가중 β1/β2 = 0.3/0.7 | 20/20 | 0/20 |
| 착석 계수 γ = 0.15 | 20/20 | 0/20 |
| 착석 계수 γ = 0.7 | 19/20 | 0/20 |
