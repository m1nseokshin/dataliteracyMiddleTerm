> **형식:** HTML 슬라이드덱 (1920×1080, 16:9). `앱_열기.command`로 열고 `F`로 전체화면, `← →`로 이동

## 발표 흐름 (한 줄 스토리)

문제 제기 → 무엇을 재는가 → 어떤 데이터인가 → **데이터가 없는 부분을 어떻게 메웠나(핵심 리터러시)** → 계산 방법 → 결과(시나리오 A·B) → 직접 조작 → 결론
